Setup notes

  • Set TARGET_SESSION_COOKIE to allow this server to fetch authenticated target-page HTML.
  • Set TRANSLATION_API_URL and TRANSLATION_API_KEY for an OpenAI-compatible chat-completions endpoint.
  • Alternatively set LIBRETRANSLATE_URL and optional LIBRETRANSLATE_API_KEY.
  • OpenXLab access keys can be stored as OPENXLAB_AK and OPENXLAB_SK; wire them to a compatible endpoint once your account/API route is confirmed.
